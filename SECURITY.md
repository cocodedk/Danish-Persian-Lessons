# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue.

Report it privately using one of these channels:

- **Preferred:** use the **"Report a vulnerability"** button on this repository's **Security** tab (a GitHub private security advisory).
- **Email:** [babak@cocode.dk](mailto:babak@cocode.dk)

Please include as much detail as possible: steps to reproduce, affected version/commit, and potential impact.

## Response Timeline

- **Acknowledgement:** within 5 business days of your report.
- **Fix target:** within 30 days, depending on severity and complexity.

We'll keep you informed of progress and let you know once a fix has been released.
